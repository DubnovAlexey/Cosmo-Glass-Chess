# Stockfish — third-party engine

`stockfish.js` in this folder is the Stockfish chess engine compiled to JavaScript. It is **not** my code.

- Authors: T. Romstad, M. Costalba, J. Kiiski, G. Linscott and other contributors; multi-variant support by Daniel Dugovic and contributors; JavaScript build by Nathan Rugg and contributors.
- Licence: **GNU General Public License v3** — https://www.gnu.org/licenses/gpl-3.0.html
- Source code: https://github.com/official-stockfish/Stockfish (engine), https://github.com/nmrugg/stockfish.js (JavaScript build), https://github.com/ddugovic/Stockfish (multi-variant fork).

The file is used unchanged and runs in a Web Worker (`js/chess-logic.js`).
